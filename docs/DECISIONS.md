# StudyNova decisions

Decisions that shape the code or content, newest last. The initial set comes from `docs/BUILD-PLAN.md`.

| # | Decision | Decided by | Enforced in |
|---|---|---|---|
| D1 | **Static, free, private by design.** Plain HTML/CSS/ES modules on GitHub Pages; no page build step, no runtime or dev dependencies, no accounts, no tracking. Progress is saved only in this browser. | Owner (build plan) | `package.json` (no dependencies), `tests/unit/workflow.test.js`, `tests/unit/privacy.test.js` |
| D2 | **Four subjects, one hub.** Math, ELA, Social Studies and Science, each with its own teacher (shown by role, e.g. "Math teacher", never a name), units and week, plus one combined This Week view. Hash routes: `#/`, `#/week`, `#/math`, `#/ela`, `#/social-studies`, `#/science`, `#/parent`. | Owner (build plan) | `js/app.js`, `scripts/validate-data.js` (role check), `tests/hub.browser.mjs` |
| D3 | **Math is the NumberNova app, moved into `math/`.** The hub's Math page links to `math/index.html`. Math keeps NumberNova's browser keys (`gml:v1:*`); the site is on the same origin (bazeocrisy.github.io), so existing progress carries over. Its tests moved to `tests/math/` and run in `npm test` / `npm run test:browser`. | Owner (build plan) | `math/`, `tests/math/`, `scripts/run-browser-tests.mjs` |
| D4 | **Chapter 5 and Lesson 5-1 were not moved.** They were built on scanned textbook pages, which must not be published. Chapter 5 returns later as original problems. | Owner (build plan) | `scripts/build-site.js` (`FORBIDDEN`), `tests/unit/privacy.test.js` |
| D5 | **Preview-first publishing from an allowlist.** One Pages site: production from `main` at `/StudyNova/`, preview from `develop` at `/StudyNova/preview/`. Every push to either branch tests both, builds both from the allowlist, browser-tests both built sites, then publishes together; pull requests only check. Merges into `main` need the owner's explicit approval per pull request. | Owner (build plan, same model as Study Scoop) | `.github/workflows/pages.yml`, `scripts/build-site.js`, `tests/unit/workflow.test.js`, `docs/DEPLOYMENT.md` |
| D6 | **Privacy.** No student, teacher, school or family names; no textbook scans or worksheet photos; no copied answer keys. The blocked-name list is kept in one place (`scripts/privacy.js`) and used by both the build verifier and the unit tests. Raw material stays in git-ignored `private/`. | Owner (build plan) | `scripts/privacy.js`, `scripts/build-site.js`, `tests/unit/privacy.test.js`, `.gitignore` |
| D7 | **Nothing from other sites.** No external scripts, stylesheets, fonts, CDNs or analytics; fonts are self-hosted; links to other sites are `https://` only; a strict Content Security Policy on the hub. | Owner (build plan: "no tracking") | `scripts/build-site.js`, `tests/unit/privacy.test.js`, `tests/hub.browser.mjs` (no foreign requests) |
| D8 | **Data model.** `data/subjects.json` (four subjects), `data/weeks/index.json` (posted weeks, Mondays, ISO dates, `current`), `data/weeks/<YYYY-MM-DD>.json` with one block per subject (topics, homework, assessments with dates, vocabulary, notes, resources). Any subject may be missing from a week; empty weeks show friendly "nothing posted yet" states. An unlisted week file is a draft and is not published. | Owner (build plan); format in `data/SCHEMA.md` | `scripts/validate-data.js`, `tests/unit/data.test.js`, build verifier, `tests/hub.browser.mjs` (empty states) |
| D9 | **Site path `/StudyNova/`.** Local serving and tests use the same path as Pages; every link inside the site is relative, so the same files work at `/StudyNova/` and `/StudyNova/preview/`. | Owner (build plan) | `tests/lib/harness.js`, `tests/serve.js`, build verifier (absolute paths refused) |
| D10 | **Original content aligned to Georgia standards.** Units follow the Georgia Standards of Excellence for grade 5 (Math, ELA, Social Studies, Science). Questions, explanations and pictures are written for StudyNova; every answer key is checked by a test. | Owner | `.claude/agents/grade5-curriculum-developer.md`, `.claude/skills/build-unit` |
| D11 | **Published size cap.** The built site must stay under 40 MB (the preview doubles what Pages stores). | Developer (infrastructure) | `scripts/build-site.js` (`MAX_BYTES`) |
