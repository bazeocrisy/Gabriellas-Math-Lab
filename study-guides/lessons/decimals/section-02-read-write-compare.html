Reading Decimals in Words

Goal: I can read and write a decimal in words.
Show how

Write 4.735 in words.

  1. Read the whole-number part: 4 → “four”.
  2. Say “and” for the decimal point.
  3. Read the digits after the point as one number: 735 → “seven hundred thirty-five”.
  4. Say the place of the last digit. The 5 is in the thousandths place → “thousandths”.

four and seven hundred thirty-five thousandths

Why it works: 0.735 is 735 thousandths, so saying the last place names the size of every piece. Use “and” only for the decimal point.

Writing Decimals from Words

Goal: I can write the standard form of a decimal given in words.
Show how

Write “six and eight hundredths” as a decimal.

  1. The word before “and” is the whole number: 6. Write 6.
  2. The last word is hundredths, so there are 2 places after the point.
  3. “Eight” must end in the hundredths place: 6._8
  4. Fill the empty tenths place with a 0: 6.08 not 6.8!
Why it works: the place word tells you how many digits go after the point: tenths = 1, hundredths = 2, thousandths = 3.

Comparing Decimals with >, <, =

Goal: I can compare two decimals using place value.
Show how

Compare 0.8 and 0.75. Write >, <, or =.

  1. Line up the decimal points.
  2. Give both the same number of places: 0.8 = 0.80.
  3. Compare from the left. Ones: 0 = 0. Tenths: 8 > 7. Stop: the first different place decides.
  4. 0.8 > 0.75
0.80
0.75
Why it works: 0.80 is 80 hundredths and 0.75 is 75 hundredths. A tenth is worth 10 hundredths, so 8 tenths beat 7 tenths no matter what comes after. More digits does not mean bigger. If every digit matches after adding zeros, they are equal: 0.7 = 0.70.

Comparing on a Number Line

Goal: I can read decimals on a number line and compare them.
Show how

Points A and B are on the number line. Which is greater?

  1. Find the size of one jump: from 0.3 to 0.4 in 10 jumps, so each jump is 0.01. (From 0.6 to 0.61, each jump is 0.001.)
  2. Read each point: A is 2 jumps past 0.3 → 0.32. B is 7 jumps past 0.3 → 0.37.
  3. On a number line, numbers get greater to the right. B is to the right of A.
  4. 0.37 > 0.32
Why it works: each jump to the right adds the same amount, so the point farther right is always the greater number.

Ordering from Least to Greatest

Goal: I can put decimals in order from least to greatest.
Show how

Order 0.5, 0.45, 0.405 from least to greatest.

0.500
0.450
0.405
  1. Line up the decimal points and write zeros so all have 3 places.
  2. Compare the tenths: 5 is biggest, so 0.5 is the greatest.
  3. 0.450 and 0.405 tie in tenths (4). Compare hundredths: 0 < 5, so 0.405 is the least.
  4. Least to greatest: 0.405, 0.45, 0.5
Why it works: ordering is comparing again and again. Start at the biggest place; only go to the next place when digits tie.

Ordering from Greatest to Least

Goal: I can put decimals in order from greatest to least.
Show how

Order 1.2, 1.02, 1.202 from greatest to least.

1.200
1.020
1.202
  1. Line up the points; write zeros so all have 3 places. The ones all tie (1).
  2. Tenths: 1.02 has 0 tenths, so it is the least.
  3. 1.200 and 1.202 tie in tenths and hundredths. Thousandths: 2 > 0, so 1.202 is the greatest.
  4. Greatest to least: 1.202, 1.2, 1.02
Why it works: it is the same comparing as 2.6. Just write the list starting with the greatest number. Check: the first number should be the biggest.
